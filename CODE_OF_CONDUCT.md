# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone taking part in issues, discussions, pull requests and other project spaces is expected to follow it.

In short: be respectful and constructive, assume good intent, and do not harass, insult or discriminate against anyone.

To report unacceptable behavior, contact the maintainer privately through the repository's **Security** tab (**Report a vulnerability**) or by a direct message on GitHub. Reports are handled confidentially.
